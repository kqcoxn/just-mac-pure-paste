## 下载与使用

- Apple Silicon（M 系列芯片）：选择文件名含 `arm64` 的 ZIP。
- Intel Mac：选择文件名含 `x86_64` 的 ZIP。
- 支持 macOS 14 及以上；解压后将 Just Pure Paste.app 放入“应用程序”目录。
- 默认纯文本粘贴快捷键为 **⇧⌘V**，可在设置中修改。
- 首次使用需手动授予“辅助功能”权限，系统询问剪贴板访问时也需允许。
- 粘贴后剪贴板保持纯文本，不恢复原格式。

这些构建使用 ad-hoc 签名，**未使用 Apple Developer ID 签名，也未公证**。从网络下载后可能被 Gatekeeper 阻止；确认来源可信后，可在系统设置 → 隐私与安全性中按系统提示允许打开，无需关闭系统安全功能。更新后可能需要重新授予辅助功能权限。

`SHA256SUMS.txt` 提供下载文件的 SHA-256 校验值。CI 验证编译、自动测试、打包与签名完整性，不代表所有应用中的模拟粘贴已通过实测。
