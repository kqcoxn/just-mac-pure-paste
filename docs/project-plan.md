# 纯文本粘贴项目方案

状态：已确认，作为第一版实现与验收的依据。

## 产品目标

开发一个轻量的 macOS 菜单栏应用。用户复制内容后，按下自行设置的全局快捷键，即可向当前应用的输入位置粘贴纯文本。

坚持单一用途：只做纯文本粘贴。第一阶段以本机自用、常用应用中的可靠体验为目标。

本文约定产品行为和实现边界，不包含开发工具安装、配置或入门教程。

## 第一版功能

- 菜单栏常驻入口，用于打开设置、查看权限状态及退出应用。
- 一个可自定义并持久保存的全局快捷键；重启应用后继续生效。
- 辅助功能权限状态检查、用途说明和授权引导。
- 按快捷键执行纯文本粘贴，保持目标应用及输入位置的焦点。
- 对无文本、权限缺失或执行失败提供简短、明确的反馈，避免静默失败或频繁弹窗。

快捷键应支持用户配置并提示可检测到的冲突，不覆盖普通的 ⌘V。默认组合为 **⇧⌘V（Shift + Command + V）**，不假定该组合在所有应用中都无冲突。

## 粘贴行为

正常流程：

1. 接收全局快捷键事件，检查执行所需权限。
2. 确认目标仍为用户正在使用的应用，并处理尚未释放的修饰键。
3. 读取剪贴板的文本表示；没有可用文本时结束操作，保留剪贴板原内容。
4. 将剪贴板替换为仅含纯文本类型的内容。
5. 向目标应用发送一次 ⌘V 粘贴按键。

纯文本处理仅移除来源格式，不改变文本本身：保留中文、换行、空格、制表符和 emoji，不主动裁剪空白、改写链接或清洗内容。文本在目标应用中采用目标输入框的样式。

对于只有图片、文件或其他非文本数据的剪贴板，不进行转换，也不发送粘贴按键。混合内容若有可用文本表示，则使用其文本表示。

第一版转换成功后，剪贴板保持纯文本，不自动恢复原来的富文本内容。应在设置中明确说明这一行为。自动恢复涉及目标应用异步读取和用户再次复制的竞争问题，暂不实现。

如在转换后未能发送粘贴，应明确反馈失败；不宣称按键事件已发送就代表目标应用已完成粘贴。

## 技术方案

| 职责 | 方案 |
| --- | --- |
| 应用语言 | Swift |
| 设置与权限提示界面 | SwiftUI |
| 菜单栏入口 | SwiftUI `MenuBarExtra` |
| 剪贴板读写 | AppKit `NSPasteboard` |
| 全局快捷键及录制控件 | `KeyboardShortcuts` |
| 模拟粘贴按键 | Core Graphics `CGEvent`，验证权限及跨应用行为 |
| 简单设置持久化 | `UserDefaults`，快捷键配置优先复用库的能力 |

实现应分离菜单栏与设置界面、快捷键注册、权限检查、剪贴板转换及粘贴协调逻辑。保持结构简单，无需为第一版引入复杂架构。

全局快捷键注册与向其他应用发送按键是不同能力；快捷键库支持沙盒，不代表自动粘贴流程也已满足沙盒限制。

最低支持 macOS 14，使用 Swift 6 语言模式，依赖 KeyboardShortcuts 固定为 3.1.0。使用 Swift Package Manager 组织应用与测试，通过脚本生成本机架构的 `.app`，具体构建兼容处理见 README。

## 可靠性与隐私

- 应用处理快捷键时不抢走前台焦点。
- 处理修饰键释放、连续触发和重复事件，避免误发其他快捷键或重复粘贴。
- 如果执行期间目标应用改变，取消本次操作，避免粘贴到意外位置。
- 检查剪贴板在读取与写入之间是否改变，避免覆盖用户刚复制的新内容。
- 权限未授予或已撤销时，不修改剪贴板，提示用户完成授权。
- 仅在用户主动触发时读取剪贴板，不持续轮询、记录历史或上传内容。
- 日志不得包含剪贴板正文。
- 针对支持的系统版本验证剪贴板访问限制与提示行为。

## 暂不包含

- 剪贴板历史、收藏与搜索。
- 云同步、账号和联网服务。
- 后台自动清除复制内容的格式。
- 自动恢复原始剪贴板。
- 文本清洗、翻译、改写或 OCR。
- 开机启动、自动更新和复杂设置。
- 第一版上架 Mac App Store。

后续确需发布时，再规划签名、公证和分发。如果决定上架 Mac App Store，先验证沙盒下完整粘贴流程的可行性。

## 实现顺序

1. 建立最小应用，验证剪贴板文本读取和纯文本写回。
2. 接入全局快捷键、权限检查与模拟粘贴，验证完整流程。
3. 完成菜单栏、快捷键设置、权限引导及错误反馈。
4. 在常用应用中验证焦点、按键时序、内容保真和异常情况。
5. 在 README 记录运行方式、实际支持的系统版本及已知限制。

## 验收标准

- 应用启动后可从菜单栏访问设置并正常退出。
- 修改快捷键后，新组合生效；重启后配置仍保留。
- 从网页或富文本文档复制带字体、颜色等样式的文本，触发后只粘贴文本，保留换行与 Unicode 字符。
- 普通 ⌘V 的系统行为不被全局接管。
- 粘贴成功后剪贴板保持纯文本，与设置中的说明一致。
- 纯图片、纯文件、空剪贴板不会被清空，也不会触发意外粘贴。
- 权限缺失或撤销时有明确反馈，剪贴板保持不变。
- 连续触发或修饰键尚未释放时，不出现重复粘贴或其他快捷键动作。
- 操作不抢焦点，目标变化时取消执行。
- 至少在实际使用的浏览器、代码编辑器、聊天软件和文档软件中各验证一个应用，记录名称、版本、结果及限制。

兼容性以实际验证结果为准，不承诺所有应用、输入框和系统安全场景都能自动粘贴。
