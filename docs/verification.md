# 第一版验证记录

验证日期：2026-09-16。

## 环境与产物

- 本机：Apple Silicon，macOS 27.0（26A428）。
- 编译器：Apple Swift 6.4；项目明确启用 Swift 6 语言模式。
- 构建：Command Line Tools，编译时指定本机 macOS 26.5 SDK，使用脚本中的兼容处理。
- 最低系统版本：macOS 14.0（应用 Info.plist 与 Mach-O 最低部署版本均为 14.0）。macOS 14 本机实测未完成。
- 产物：`dist/Just Pure Paste.app`，arm64，版本 0.1.0，非沙盒，ad-hoc 签名。
- KeyboardShortcuts 固定为 3.1.0，提交 `772133d9dbe800fdac0473226822994c5c162c58`。兼容转换与资源路径调整见 README。

自动测试包含：

- 文本 Unicode、空格、制表符与换行保真，去除 HTML/富文本类型。
- 仅 RTF 内容的文本提取，以及混合图片和文本的文本读取。
- 空剪贴板、空字符串、图片和文件复制均不修改剪贴板。
- 权限缺失、无目标应用、按键创建失败、写入失败时不发送粘贴。
- 等待修饰键释放、超时、等待期间的目标切换、权限撤销和剪贴板更新。
- 读取后再次验证环境；重复触发不并发；取消后可接受下一次操作。

剪贴板测试使用 `NSPasteboard.withUniqueName()`；模拟按键使用测试替身，不在测试套件中向真实应用发送按键。
